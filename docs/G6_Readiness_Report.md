  - Because transaction frequency was higher in the first half of the validation timeframe, the actual number of transactions meeting this timestamp filter is **exactly 27,390 transactions** (containing $971$ fraud cases, $3.55\%$ prevalence).
  - **Authoritative Resolution:** The authoritative ground-truth sample size for S2 is **$27,390$ transactions**. The G4 figure was an unadjusted uniform estimate; the G5 evaluation executed the actual filter code against real transactions. No artifacts were modified or retuned.

The **Claim Ledger** ([governance/claim_ledger.py](file:///c:/Users/archi/OneDrive/Desktop/SignalGate/governance/claim_ledger.py)) enforces rigorous evidentiary standards:

### Core Capabilities:
1. **Ground-Truth Validation**: Reads only immutable saved artifacts ([results/results.json](file:///c:/Users/archi/OneDrive/Desktop/SignalGate/results/results.json), [results/pre_eval_freeze_record.json](file:///c:/Users/archi/OneDrive/Desktop/SignalGate/results/pre_eval_freeze_record.json)).
2. **Schema & Typings**: Enforces Pydantic typed contracts: `ReportableClaim` and `LedgerVerificationResult`.
3. **Evidence Classification**: Categorizes every claim strictly into one of six standard classes:
   - `measured real data`
   - `measured synthetic data`

   - `planned work`
   - `unavailable evidence`
